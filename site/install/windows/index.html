Проверить компьютер

В PowerShell из папки релиза: .\scripts\windows-preflight.ps1. Установка зависимостей выполняется отдельно и только с явным -Install.

Проверить bootstrap

.\scripts\windows-bootstrap.ps1 создаёт локальные секреты, но ничего не запускает. Для старта: .\scripts\windows-bootstrap.ps1 -Start.
