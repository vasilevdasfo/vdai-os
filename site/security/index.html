Секреты

Пароли, API keys и токены не передаются участникам или боту.

Изоляция

Общая production-база заблокирована до поддерживаемой RLS или workspace isolation. Лицензия не обходится.

Восстановление

Перед изменением: dump, volume snapshot и restore drill в отдельной базе.

Приглашения

Именные, одноразовые, ограниченные по времени; adapter выключен до HTTPS, isolation и backup proof.
